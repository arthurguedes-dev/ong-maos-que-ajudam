# ONG Mãos que Ajudam

## Apresentação do projeto

Projeto acadêmico de desenvolvimento front-end.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

Para executar o projeto localmente, abra o arquivo `html/index.html` em um navegador.

## Versionamento

O projeto utiliza Git e GitHub para controle de versões, com as branches `main`, `develop` e `feature/acessibilidade`. Também foram utilizados commits seguindo o padrão Conventional Commits.
